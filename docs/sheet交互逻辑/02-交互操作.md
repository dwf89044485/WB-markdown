# Sheet 交互逻辑

## 一、打开流程

`openSheet(frameRefs)` 的执行顺序：

```
① 解析帧     → getFrames(frameRefs) 从 scenario.sheetFrames 查找
② 清空 body  → body.innerHTML = ''
③ 空状态检测   → 既无 events 又无 todos 则显示"当前状态暂无新增事件。"
④ 复位高度    → resetSheetHeight() 回到 40%，移除 expanded class
⑤ 显示遮罩    → overlay: vis → rAF → show class（opacity 0.28s）
⑥ 流式渲染    → streamSheetContent(frames, baseline)
```

核心原则：**打开时永远是 40%**，不管后续内容加载多少，面板高度不自动变化。

## 二、关闭

| 方式 | 触发条件 | 代码路径 |
|------|---------|---------|
| 点击遮罩背景 | `event.target === overlay` | `maybeClose(e)` → `closeSheet()` |
| 关闭按钮 | 右上角 glass 按钮点击 | `closeSheet()` |
| 下拉关闭（40% 状态） | 下拖超过 40px 阈值 | `closeSheet()` |

`closeSheet()` 流程：

```
① resetSheetHeight() → 移除 inline height 和 expanded class
② overlay: 'sheet-overlay vis'（移除 show → 触发 opacity 淡出）
③ transitionend → overlay: 'sheet-overlay'（完全隐藏）
```

## 三、尺寸管理

### 3.1 两种高度状态

| 状态 | CSS | overflow-y | 含义 |
|------|-----|-----------|------|
| 折叠态 | `height: 40%` | `hidden` | 默认大小，内容超限被裁剪 |
| 展开态 | `height: 80%` + `class="expanded"` | `auto` | 手动拖拽展开，内容可滚动 |

`expanded` class 控制 body 的滚动权限：
- 有 `expanded` → `overflow-y: auto`，用户能手动滚动
- 无 `expanded` → `overflow-y: hidden`，但代码内仍可设 `scrollTop` 控制偏移

### 3.2 ~已删除~（没有自动展开）

面板高度**只由拖拽改变**。无论流式加载多少内容，面板始终保持在 40%，不自动展开。内容溢出完全由 `overflow-y: hidden` 裁剪，用户展开到 80% 后才可看到全部内容。

### 3.3 滚动行为

#### 流式输出中（animated=true）

每次追加内容后触发 `scrollSheetBody()`：

| 面板状态 | overflow-y | 行为 |
|---------|-----------|------|
| 40% | hidden | `scrollTop = scrollHeight`。新内容被追加到底部后，可见窗口偏移到底部，用户看到最新内容。不可见内容在视口上方。 |
| 80% | auto | 判断 scrollTop 位置：<br>· **在底部附近**（`scrollTop >= scrollHeight - clientHeight - threshold`）→ 滚到底部展示最新内容<br>· **用户已翻上去了** → 不动，不打断用户阅读 |

#### 流式结束 / 静态已完成（animated=false）

一次性渲染所有内容后，`scrollTop = 0`，用户从最早的内容开始看起。

## 四、拖拽交互

模块：`initSheetDrag()`（`engine/sheet.js`）

### 4.1 状态机

```
                    onStart                    onMove
40% ──────────→  拦截整个面板   ────→  dy > 0: 展开
                                       dy < -40: 关闭

80% + scrollTop=0 ─→ 记录但不拦截 ─→  首次 dy < 0: 转为折叠模式
                                       首次 dy ≥ 0: 释放（走滚动）

80% + scrollTop>0 ─→ 直接 return（不拦截，走原生滚动）
```

### 4.2 关键参数

| 参数 | 值 | 含义 |
|------|-----|------|
| `dy = startY - currentY` | >0 上拖，<0 下拖 | 方向 |
| 关闭阈值 | `dy < -40` | 下拖超过 40px 关闭 |
| expanded 切换 | `pct >= 70` | 拖拽中实时切换 |
| 吸附阈值 | 展开 `>= 50` / 折叠 `< 75`（双向滞后） | 松手决定最终高度：从 40% 拉起过半即展开，从 80% 拉下到 75% 即折叠 |

### 4.3 行为矩阵

| 当前状态 | 手势 | 结果 |
|---------|------|------|
| 40% | 上拖 | 面板展开到 80%，跟随手指 |
| 40% | 下拖 > 40px | 关闭 sheet |
| 40% | 点/短拖 | 松手吸附回 40% |
| 80% + 内容在顶部 | 下拖 | 面板折叠回 40%，跟随手指 |

> **回到 40% 后内容在顶**：80% → 40% 的折叠触发条件是内容已在顶部（`scrollTop === 0`），所以折叠后内容自然停在顶部。
| 80% + 内容在顶部 | 上拖 | 释放拖拽，内容向上滚动 |
| 80% + 内容不在顶部 | 任何方向 | 不拦截，正常滚动 |

## 五、遮罩事件冒泡

遮罩使用 `onclick="maybeClose(event)"`，检查 `event.target === overlay`。
- 点击 overlay 背景 → 关闭
- 点击 sheet 内部或 close button → 不关闭（target 不是 overlay）
