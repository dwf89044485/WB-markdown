# 工具调用节点 · 状态约定

> 这是工具调用节点（Status Line）交互的**核心约定**，写下来以防以后忘。

## 一句话总结

**两个状态，文字前缀「正在」是唯一的状态标记。**

```
进行中：正在执行命令
已完成：执行命令
```

——同一工具调用在两个状态共用同一段文案，仅靠前缀「正在」区分。

## 详细规则

### 两个状态

| 状态 | 标签 | 视觉 |
|------|------|------|
| 进行中 | `正在X` | 行灰 `#999`，扫光 1.15s 左→右循环 |
| 已完成 | `X` | 行浅灰 `rgba(0,0,0,0.30)`，扫光消失，`›` 仍在 |

### 关键规则

1. **前缀「正在」是进行中的唯一标记**
   - 加上 → 进行中
   - 去掉 → 已完成
   - 状态切换 = 改这一个前缀

2. **已完成不加「已」前缀**
   - ✅ 正确：进行中 `正在搜索网页` → 已完成 `搜索网页`
   - ❌ 错误：进行中 `正在搜索网页` → 已完成 `已搜索网页`

3. **基础文案两态共用，不变**
   - 改前缀是切换状态的唯一方式，不替换为其他描述

## 多条叠加

- 连续多个工具调用合并为**同一条节点**，标签用「、」分隔：
  - 多个进行中：`正在搜索网页、正在创建文件、正在委派 Subagent`
  - 全部完成：`搜索网页、创建文件、委派 Subagent`
- 多条节点同时存在时，**已完成留上、进行中在最末**
- 扫光**只在最末那条**有——视觉上"进度在推进"而非"全屏都在闪"

## 文档展示约定

- 工具调用节点有 **3 种视觉样式**：
  - **文字** —— 默认内联（最常用）
  - **堆叠** —— 多条完成时折叠为「图标堆 + 已执行 N 项」
  - **边框** —— 卡片强调（弱化使用）
- 状态章节用「**文字**」样式（实际 status-line 按钮）实样展示，不加边框快照框
- 其他章节（设计样式 / Sheet 交互）保留视觉快照
- 例：以「执行命令」作为**通用示例**
