本文档定义对话流中**所有"工具卡片"容器**（代码块、HTML、表格、Mermaid 等）的统一外观、按钮规则、交互行为。

## 一、4 种类型一览

按"内容能否产生可视/可执行结果"划分 4 种类型：

| 类型 | 标识符 (kind) | 触发语言 | 标题示例 | 主按钮 | 次按钮组 |
|------|----------|---------|---------|--------|---------|
| 可执行类 | `executable` | `js`/`ts`/`jsx`/`tsx`/`python`/`bash`/`shell`/`zsh` | JavaScript / Python / Shell | **▶ 运行** | 复制 / 分享 / 全屏 |
| HTML 内容 | `view` | `html` | HTML | **● 查看** | 复制 / 分享 / 全屏 |
| 不可执行类 | `static` | `json`/`css`/`scss`/`less`/`yaml`/`xml`/`toml`/`md`/`sql`/`diff`/未识别 | JSON / CSS / YAML / 等 | 无 | 复制 / 分享 / 全屏 |
| 表格 / 可视化 | `visual` | markdown 表格 / `mermaid` | 表格 / Mermaid | 无 | 复制 / **保存图片** / 分享 / 全屏 |

> **Fallback 规则**：未在配置表中列出的语言（如 `rust`、`go`）→ 走 `static` 类型，标题取语言名首字母大写（如 "Rust" / "Go"）。

## 四、滚动吸顶行为

### 4.1 触发条件

任意工具卡片（`.tbl-outer` / `.wb-card`）顶部滚到视口上方时，工具栏应"悬浮"在顶部，紧贴 navbar 下方。

### 4.2 吸顶范围

| 卡片类型 | 吸顶内容 |
|---------|---------|
| 表格 (`visual`、有 `<thead>`) | toolbar + thead 两行 |
| 其他类型 | toolbar 一行 |

### 4.3 落点位置

ghost 顶部 = `navBar.top + navBar.height * 0.8`（navbar 80% 高度处）。这样 ghost 圆角刚好盖住 navbar 底部 20% 渐变透明区，过渡自然。

### 4.4 退场条件

满足任一即销毁：
1. 卡片完全滚出视口顶部（`rect.bottom <= stickyTop`）
2. 卡片回到视口（`rect.top >= stickyTop`）
3. 用户点了**任意**全屏按钮（包括其他卡片的）→ capture 阶段销毁，避免 ghost 残留覆盖 overlay

### 4.5 ghost 内按钮的转发

ghost 是只读副本，自身不承担行为。点 ghost 的按钮 → 转发到原始卡片同位置按钮：
- 全屏：先销毁 ghost，再触发原按钮（避免 ghost 浮在 overlay 上）
- 复制 / 分享 / 保存图片：直接转发（行为一致）

### 4.6 视觉

ghost 容器：
- 同样 10px 上圆角、`box-shadow: 0 2px 12px rgba(0,0,0,0.08)`
- 外壳 **不画下边框**（避免和 toolbar 内部下边框形成双线）
- 透明区域底色 `#fafafa`（页面背景），防止圆角处透出滚动内容

## 五、全屏页（二级页）

### 5.1 入口

点任意卡片的「全屏」按钮 → 进入全屏 overlay，clone `<table>` / 代码块 DOM 进入。

### 5.2 桌面端

手机壳从 393×852（竖屏）变形为 852×393（横屏），状态栏/对话流/输入框全部隐藏。

### 5.3 移动端

竖向全屏，不旋转设备，按视口实际方向适配。

### 5.4 二级页内的工具栏

全屏页保留独立工具栏（`.tbl-fs-btn[data-action]`），按钮含：复制 / 保存图片 / 分享。
全屏页内**没有"全屏"按钮**（语义上已经是全屏了）。

### 5.5 动效设计原则

> 来源：session `63e9a9c8`（2026 年 6 月）

Sheet 展开/收起必须有完整的过渡动效，关键点：

**问题案例**：收起动效"消失"——展开有动画，收起没有。

**根因**：`.code-sheet-overlay` 的 `transition` 只声明了 `opacity`，没声明 `visibility`。CSS `visibility` 的机制是：从 `visible → hidden` 时，如果 `visibility` 没在 `transition` 里，改变会**立即生效**。收起时面板下滑动画虽触发，但父容器瞬间 `visibility:hidden`，动效看不见。

**正确做法**：

```css
/* ❌ 错误 —— 收起无动效 */
transition: opacity .28s;

/* ✅ 正确 —— 展开/收起都有动效 */
transition: opacity .28s, visibility .28s;
```

- `visibility` 加入 `transition` 后，`visible → hidden` 会等到过渡结束时才切换，收起动效完整
- 时长必须和面板滑动时长一致（`.28s`），避免时序错位
- 展开：`overlay visibility:visible + opacity:1` → `panel transform: translateY(0)`
- 收起：`panel transform: translateY(102%)` → 等 `.28s` → `overlay visibility:hidden + opacity:0`

## 六、全屏 Sheet 行为规范

> 实现位置：`engine/code-fullscreen-sheet.js`
> 最后更新：2026-06-28

### 6.1 全屏路由规则

点任意卡片的「全屏」按钮后，按卡片类型分流：

| 卡片类型 | 全屏走向 | 实现文件 |
|---------|---------|---------|
| 表格（`thead` 存在） | 横屏 overlay（手机壳变形 393×852 → 852×393） | `engine/table-fullscreen.js` |
| Mermaid（`wb-card-visual`） | 横屏 overlay（同表格路径，SVG 全屏展示） | `engine/table-fullscreen.js` |
| 其他（executable / view / static） | 底部 Sheet 滑出（`.code-sheet-overlay`） | `engine/code-fullscreen-sheet.js` |

> **路由拦截在 capture 阶段**：`code-fullscreen-sheet.js` 先注册 click handler（capture），表格/Mermaid 直接 `return` 让 `table-fullscreen.js` 处理；非表格才 `preventDefault` + `openSheet()`。

### 6.2 四种类型的 Sheet 行为差异

#### executable（JS / Python / Shell 等）

| 区域 | 内容 |
|------|------|
| 顶栏左侧 | 标题（如 "JavaScript" / "Python"） |
| 顶栏右侧主按钮 | ▶ **运行**（占位，待实现沙箱执行） |
| 顶栏右侧次按钮 | 复制 / 分享 / 关闭 |
| 内容区 | 代码原文（`<pre><code>` + highlight.js 染色） |

#### view（HTML）

| 区域 | 内容 |
|------|------|
| 顶栏左侧 | 标题 "HTML" |
| 顶栏右侧主按钮 | **预览** / **代码** 切换（segment 形态，非双按钮） |
| 顶栏右侧次按钮 | 复制 / 分享 / 关闭 |
| 内容区 | 默认进 **代码视图**（`openSheet(card, { htmlMode:'code' })`）；点「预览」主按钮后切为 `<iframe sandbox>` 渲染 HTML 实际效果 |

> **进入 Sheet 的默认模式**：
> - 点工具栏「● 查看」按钮 → 默认进 **preview**（沙箱预览）
> - 点「全屏」按钮 → 默认进 **code**（源码审查）
>
> 两种入口在 `code-fullscreen-sheet.js` 里通过 `opts.htmlMode` 区分。

#### static（JSON / CSS / YAML 等）

| 区域 | 内容 |
|------|------|
| 顶栏左侧 | 标题（如 "JSON" / "CSS"） |
| 顶栏右侧主按钮 | 无 |
| 顶栏右侧次按钮 | 复制 / 分享 / 关闭 |
| 内容区 | 代码原文（`<pre><code>` + highlight.js 染色） |

#### visual（表格 / Mermaid）

不走 `code-fullscreen-sheet.js`，走 `table-fullscreen.js` 的横屏 overlay 路径，见第五节。

### 6.3 Sheet 视觉规范

| 属性 | 值 |
|------|---|
| 进场动效 | overlay opacity 0→1 + panel transform translateY(102%)→translateY(0) |
| 退场动效 | panel transform translateY(0)→translateY(102%)，**等 .28s** 后 overlay 才 hidden（visibility 必须在 transition 里） |
| Sheet 顶部圆角 | 30px |
| Sheet 底色 | `#fafafa` |
| Sheet 高度 | 撑高到 navbar 下方（不覆盖 navbar） |
| 内容区代码 | 保留 highlight.js 染色，不做二次处理 |

### 6.4 按钮行为汇总

| 按钮 | 适用类型 | 行为 |
|------|---------|------|
| ▶ 运行 | executable | 占位无操作（待沙箱执行） |
| 预览/代码 | view | 切换 `htmlMode`，重绘内容区（代码 ↔ iframe） |
| 复制 | 全部 | `clipboard.writeText(state.code)` |
| 保存图片 | visual（仅表格全屏 overlay 内） | 表格 → 制表符 TSV；后续 html2canvas |
| 分享 | 全部 | `navigator.share` 或回退复制 |
| 关闭 | 全部 | `closeSheet()`，320ms 后释放 iframe |

## 七、语法高亮

代码块（kind = `executable`/`view`/`static`）通过 `highlight.js@11.10.0` 自动染色：
- CDN：`cdnjs.cloudflare.com/.../highlight.js/11.10.0/highlight.min.js`
- 主题：GitHub Light（`github.min.css`）
- 触发时机：
  - typewriter 流式输出场景：`appendHTMLTypedTo` 末尾扫描本批新增的 `<pre><code>` 统一调 `hljs.highlightElement()`
  - showcase 静态渲染场景：`renderShowcase` 末尾遍历 `mount.querySelectorAll('pre code')` 调用
- CSS 适配：覆盖 `.hljs` 主题自带的 `padding`/`background`，让外观由 `.wb-card-body pre` 统一管理

> **Mermaid 不走 highlight.js**——它走可视化渲染，不是源码染色。当前为占位（显示源码字符串），后续接入 `mermaid` 库时，`<code class="lang-mermaid">` 会被解析成 SVG。
