# 大屏适配逻辑

## 设计判断

两根断点都来自一个算式：

- **1200px**：1200 − 300（侧边栏）− 300（产物栏）= 600px，内容栏刚好触及移动端断点，两档自然衔接。
- **600px**：低于此宽度，300px 的侧边栏会过度挤压内容栏，切换为单栏 + Sheet 更合理。

核心策略：**宽屏常驻、中屏浮层、窄屏 Sheet**。产物展示形式随屏幕空间动态切换，不做多套布局。

---

## 适配策略

| 内容区可用宽度 | 布局 | 侧边栏 | 产物形态 | 触发方式 |
|---|---|---|---|---|
| > 1200px | 三栏 | 300px 常驻 | 右侧栏 300px | 常驻，无需触发 |
| 600–1200px | 双栏 | 300px 常驻 | 浮层（覆盖内容区） | 点击触发 |
| < 600px | 单栏 | 隐藏 | 底部 Sheet | 点击触发 |

### > 1200px · 三栏

产物在右侧栏常驻，所见即所得。

```
┌──────────┬──────────────────────────┬──────────┐
│  侧边栏   │      内容栏（弹性）      │  产物栏   │
│  300px   │      fill remaining      │  300px   │
└──────────┴──────────────────────────┴──────────┘
```

### 600–1200px · 双栏 + 浮层

产物退为浮层，含背景模糊，视觉悬浮于内容之上。

```
┌──────────┬──────────────────────────┐
│  侧边栏   │      内容栏（弹性）      │
│  300px   │      fill remaining         │
└──────────┴──────────────────────────┘
                    ↑
            产物以浮层形式覆盖在内容区上方
```

### < 600px · 单栏 + Sheet

侧边栏退场，产物转底部 Sheet，从下往上弹出。

```
┌──────────────────────┐
│    内容栏（全宽）    │
│                      │
│                      │
└──────────────────────┘
        ↑ 底部 Sheet 从下往上弹出
```

---

## iPad 分屏

iPad 分屏是高频场景。分屏后 WorkBuddy 的可用宽度可能跌破 600px，此时产物展示形式按**可用宽度**判断，而非设备物理宽度：

- 可用宽度 > 600px → 右侧栏（300px），常驻可见
- 可用宽度 < 600px → 底部 Sheet，宽度适配可用宽度（非全屏宽度）
