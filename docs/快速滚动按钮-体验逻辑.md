# 快速滚动按钮 — 体验逻辑（用户视角）

> 本文描述用户面对 ↑ ↓ 按钮时的操作感受和预期行为，帮助设计师/PM 评审交互是否自然。

---

## 1. 按钮长什么样

- 两个圆角图标按钮，**竖向排列在输入框右上方**
- ↑ 在上，↓ 在下，间距 8px
- 两个按钮位置固定，**一个消失不影响另一个的位置**
- 磨砂玻璃质感，半透明白底 + 微弱投影

### 按钮位置

- 始终贴在输入框右上方，距离输入框顶部 10px
- ↑ 按钮：`bottom: 10px + 36px + 8px`（在 ↓ 按钮正上方）
- ↓ 按钮：`bottom: 10px`

## 2. 什么时候能看见按钮

按钮的显隐只取决于**滚动位置**——有没有内容可看，而不是有没有"下一轮"：

| 滚动位置 | ↑ 向上按钮 | ↓ 向下按钮 |
|---|---|---|
| 对话在顶部，没有更早的内容 | 消失 | 可见 |
| 翻到中间，上下都有内容 | 可见 | 可见 |
| 对话在底部，没有更新的内容 | 可见 | 消失 |

### 出现和消失的动画

- **出现**：原地渐显（无位移），0.2s 淡入
- **消失**：直接消失（无动画），避免快速滚动时产生残影

## 3. 按一下 ↑ 会怎样

↑ 的设计原则是：**优先带你回去看上一轮说了什么，但如果你正在读的东西还没看完，先把你拉回当前这轮的开头。**

具体来说：

| 你当前看到的情况 | 按一下 ↑ 的效果 |
|---|---|
| 你在 Agent 的回复内容中间，屏幕上看不到上一条 Agent 回复的任何内容 | 回到这一轮你提问的地方（你的那条消息出现在屏幕最上方） |
| 你已经往回翻了一点，屏幕顶部露出了上一条 Agent 回复的末尾 | 直接跳到上一轮的"你问了什么"（你的消息出现在最上方） |
| 两轮交界处——上一条回复的尾巴和你的下一条提问都在屏幕里 | 跳到上一轮的你问了什么（因为当前提问你已经看到了） |
| 你已经在最早一轮，没有更早的对话了 | 按钮消失了，按不了 |

## 4. 按一下 ↓ 会怎样

↓ 很简单：**跳到下一轮的开头。**

不管你当前在看什么位置，按一下 ↓，下一轮你的提问就会出现在屏幕最上方。如果已经是最后一轮，按一下 ↓ 会直接滚到底部。如果已经在最底部，按钮消失。

## 5. 双击会怎样

↑ 和 ↓ 各自独立判断双击，互不影响。

### 首次双击：提示并毕业

当你**第一次**双击 ↑ 或 ↓，会跳转到对话顶部/底部，同时弹出一行提示：

- ↑："双击 ↑ 可跳转对话顶部"
- ↓："双击 ↓ 可跳转对话底部"

这是**一次性的教学提示**——告诉用户"你刚才的操作叫双击，记住它"。之后再次双击，只跳转，不再弹提示（**毕业**）。

### 连续快速点击：教学提示

如果用户不知道双击的存在，会通过**快速连点**来试图回到顶部。这种行为特征是：连续点击，每次间隔很短（< 500ms），中间没有停顿阅读。

当**连续快速点击 ≥ 3 次**（间隔 < 500ms，无阅读停顿）且未毕业时，弹提示："双击 ↑ 可跳转对话顶部"。

每次满足条件都会弹，直到用户学会了双击并毕业。

### 区分"定位消息"和"想回顶"

| 行为 | 间隔 | rapidStreak | 弹提示？ |
|---|---|---|---|
| 定位消息：点 → 停顿阅读 → 点 → 停顿阅读 | 每次 500ms+ | 每次重置为 1 | ❌ |
| 想回顶：点点点点（无停顿） | 每次 < 500ms | 1 → 2 → 3 → … | ✅（≥3 次且未毕业） |
| 双击 | ≤ 300ms | 归入双击分支 | ✅（仅首次，毕业后 ❌） |

## 6. 弹出提示长什么样

- 出现在按钮**左侧**（`right: calc(100% + 8px)`）
- 深灰半透明圆角小浮层，白色文字 12px
- 淡入 200ms → 保持 2.5s → 淡出 200ms
- 同一个按钮的提示不会叠加（新的替换旧的）

## 7. 几个用户可能会遇到的情况

| 场景 | 结果 |
|---|---|
| 对话在最开头，快速双击 ↑ | 不做任何事（本来就在顶部） |
| 快速先点 ↑ 再快速点 ↓（中间隔很短） | 各自算各自的，↑ 翻上、↓ 翻下，不触发跳顶/跳底 |
| Agent 正在打字输出中，我点按钮 | 可以点，正常翻页。滚动期间流式输出不会把你拉回底部 |
| 在全屏看表格，想点按钮 | 按钮隐藏了，退回到正常模式才能用 |
| AskQuestion 问答面板出现 | 按钮在问答面板右上方，不被遮挡 |
