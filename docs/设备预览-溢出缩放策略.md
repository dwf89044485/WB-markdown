# 设备预览溢出缩放策略

> 来源：session `63e9a9c8`（2026 年 6 月）
> 背景：Pad 模式支持多分辨率后，真实 Pad 尺寸（最大 1366px）容易超出浏览器可视区
> 状态：设计方案，待实施

---

## 一、问题本质

真实 Pad 尺寸在桌面浏览器里**几乎必然超出可视区**：

| 尺寸 | 竖屏 | 横屏 | 桌面可视高（典型 ~820px） |
|------|------|------|--------------------------|
| iPad mini | 744×1133 | 1133×744 | 竖屏超高 ~313px |
| iPad Pro 12.9" | 1024×1366 | 1366×1024 | 竖屏超高 ~546px，横屏也超 |
| Surface Pro 8 | 960×1440 | 1440×960 | 两向都超 |

纵向溢出是常态，不是边缘情况。当前 `overflow-y:hidden` 会直接裁掉 Pad 底部（输入框、控制面板都看不到），不可接受。

---

## 二、方案对比

### 方案 A：等比缩放（`transform: scale`） ⭐ 推荐

- 检测 `可视区 / 真实 Pad 尺寸`，算出缩放比，对 `.phone-shell` 做 `transform: scale(ratio)`
- Pad 内部仍按**真实像素**渲染（1024×1366 的 DOM），只是视觉上缩小到能放下
- 优点：**保真**——内部布局、字号、断点全部按真实尺寸生效，所见即真机比例
- 缺点：`scale` 后需用 transform 占位修正布局流；缩放比要响应 resize

### 方案 B：纵向滚动

- `.left-area` 改 `overflow-y:auto`，Pad 超高时滚动查看
- 优点：实现最简单（改一行 overflow）
- 缺点：**看不到全貌**，演示走查时要滚来滚去，体验差

### 方案 C：限制可选尺寸

- 检测放不下就禁用该选项或提示
- 缺点：等于阉割需求

---

## 三、推荐方案（方案 A）关键设计细节

### 3.1 缩放策略

```
fitScale = min(1, 可用宽 / shellW, 可用高 / shellH)
```

- 只在 `fitScale < 1`（放不下）时才缩放，放得下时 `scale = 1`
- 缩放比建议**量化**（取 0.05 步进或保留 1 位小数），避免 resize 时频繁微调导致字体抖动

### 3.2 左栏布局适配

`.phone-shell` 用 `transform-origin: center` 缩放后，它仍占据**原始未缩放的盒子尺寸**（transform 不影响布局流），会撑大 `.left-area`。

解法：用一个**外层 wrapper 设缩放后的实际尺寸**（`width = shellW * scale`），shell 在内部 scale，避免布局空洞。

### 3.3 网格 `buildGrid()` 适配

现有网格用 `getBoundingClientRect()` 读实际位置——`getBoundingClientRect` 返回的是**缩放后**的视觉尺寸，所以网格能自动贴合缩放后的 shell，基本不用改。需要验证。

### 3.4 边界

给一个底线 `minScale = 0.35`，再小就配合 `overflow-y:auto` 兜底（极端窄屏）。

## 四、相关设计决策（同 session）

### 4.1 横竖屏切换（已实施）

- CSS class 切换：`.phone-shell.phone-landscape` 交换宽高（393×852 → 852×393）
- 按钮位置：demo-controls "展示设备" 行，横屏按钮右侧
- 按钮样式：30px 高、10px 圆角、灰色底、inline-flex 布局（贴合现有按钮体系）
- 横竖屏切换不绑定 device mode（手机/Pad 各自独立）

### 4.2 Pad 多分辨率（已实施）

- 5 个预设尺寸：iPad mini 8.3 / Surface Pro 8 / iPad Pro 11" / iPad Pro 12.9" / Android Expanded
- 所有尺寸归一为**竖屏基准**（短边 = 宽），横屏时交换宽高
- 下拉控件：用原生 `<select>`（演示控制台是调试工具，最低复杂度，不造自定义下拉轮子）
- 动态尺寸：JS 写 inline CSS 变量（`root.style.setProperty('--layout-shell-w', ...)`），不写死 CSS class
- 切回手机再切回 Pad 重置为默认尺寸
